# PWA Player Generator 🎵

Generador profesional de reproductores **PWA** personalizables. Crea tu propio reproductor de música/video progresivo, expórtalo a ZIP, súbelo a GitHub o despliégalo directamente en **Vercel** con un solo clic.

## ✨ Características

- 🎨 **100% Personalizable** - Colores, diseño, tipo de reproductor, características
- 📦 **Exportación ZIP** - Descarga todos los archivos listos para deploy
- 🐙 **Subida a GitHub** - Crea repositorio y sube el código automáticamente
- ▲ **Deploy en Vercel** - Despliegue directo con un clic
- 📱 **PWA Completo** - Service Worker, Manifest, offline support
- 🎯 **SEO Optimizado** - Meta tags, Open Graph, Twitter Cards, sitemap
- 🎪 **Múltiples diseños** - Moderno, Clásico, Minimalista, Glassmorphism, Retro
- 🔄 **Múltiples tipos** - Audio, Video, Radio, Podcast, Mixto
- 🎚️ **Características** - Playlist, Shuffle, Repeat, Ecualizador, Visualizador

## 🚀 Despliegue Rápido

### En Vercel (recomendado)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/YOUR_USER/pwa-player-generator)

O usando la CLI:
```bash
npm i -g vercel
vercel --prod
```

### Local
```bash
vercel dev
# o abre index.html directamente
```

## 🛠️ Uso

1. Abre la aplicación
2. Configura tu reproductor (nombre, colores, pistas, características)
3. Previsualiza en vivo los cambios
4. Exporta a ZIP, sube a GitHub o despliega a Vercel

## 📁 Estructura del proyecto generado

```
├── index.html        # Player principal
├── manifest.json     # PWA manifest
├── sw.js            # Service Worker
```
